# WorkNeverEnd

신입 사원으로 입사해 사장까지 올라가는 회사 생활 시뮬레이션 웹 게임입니다. 업무를 처리하고, 메신저에 답하고, 이상한 부탁을 버티고, 커피타임과 점심으로 숨을 돌리고, 퇴근 후 회식까지 겪으면서 실무 용어도 함께 익힙니다.

## 실행 방법

빌드 과정이 없습니다. `index.html`을 브라우저로 열면 바로 플레이할 수 있습니다.

로컬 서버로 띄우려면:

```sh
python3 -m http.server 8000
# http://localhost:8000 접속
```

테스트할 때는 주소 뒤에 `?speed=20`을 붙이면 게임 시간이 20배 빨라집니다.

## 지금 들어 있는 것 (2단계: 사원의 하루)

- 기획 직무 사원의 하루: 09:00 출근부터 18:00 퇴근 또는 야근까지 시계가 흐름
- 업무 미니게임 세 가지: 문서 타이핑, 문서 검토(틀린 줄 찾기), 지시에 맞는 자료 고르기
- 사내 메신저: 팀장, 대리, 개발자, 동기, 타 부서의 메시지에 답하기
- 이상한 업무: 부장님 따님 과제 같은 부탁을 수락하거나 거절
- 커피타임·담배타임(너무 자주 가면 눈치), 점심 메뉴 선택, 야근
- 퇴근 후: 팀 회식(다음 날 숙취), 동기 술자리, 혼술, 집에서 쉬기
- 수치: 체력, 멘탈, 평판, 성과, 돈. 체력이나 멘탈이 0이 되면 번아웃 엔딩
- 실무 용어: 밑줄 친 용어를 누르면 뜻과 예문이 나오고 용어집에 모임
- 하루 결산과 저장(브라우저에 자동 저장, 다음 날 이어서 출근)

## 파일 구조

| 파일 | 내용 |
| --- | --- |
| `index.html` | 화면 뼈대 |
| `css/style.css` | 화면 스타일 (다크 모드, 모바일 대응) |
| `js/game.js` | 게임 진행 로직 |
| `js/ai.js` | AI 채점 대화 연결부 (기본은 꺼져 있음) |
| `js/data/terms.js` | 실무 용어 사전 |
| `js/data/tasks.js` | 업무와 이상한 업무 목록 |
| `js/data/messages.js` | 메신저 대화, 점심, 퇴근 후 선택지, 소문 |

새 업무나 용어를 추가할 때는 `js/data/` 아래 파일만 고치면 됩니다. 게임 텍스트에서 `{{용어}}`처럼 감싸면 용어 사전과 연결됩니다.

## AI 채점 대화

`js/ai.js`의 `endpoint`에 Claude API를 호출하는 서버 함수 주소를 넣으면, 메신저에서 직접 타이핑한 답을 AI가 적절함·내용·용어·명확성으로 채점합니다. API 키는 게임 코드에 넣지 않고 서버 함수에만 둡니다. 서버 함수는 아직 없고, 키가 준비되면 추가합니다.

# WorkNeverEnd

신입 사원으로 입사해 사장까지 올라가는 회사 생활 시뮬레이션 웹 게임입니다. 업무를 처리하고, 메신저에 답하고, 이상한 부탁을 버티고, 커피타임과 점심으로 숨을 돌리고, 퇴근 후 회식까지 겪으면서 실무 용어도 함께 익힙니다.

## 실행 방법

빌드 과정이 없습니다. `index.html`을 브라우저로 열면 바로 플레이할 수 있습니다.

로컬 서버로 띄우려면:

```sh
python3 -m http.server 8000
# http://localhost:8000 접속
```

테스트할 때는 주소 뒤에 `?speed=20`을 붙이면 게임 시간이 20배 빨라집니다.

## 2단계: 사원의 하루

사내 그룹웨어처럼 생긴 화면에서 기획팀 사원의 하루를 보냅니다. 상단 메뉴는 홈, 업무함, 메신저, 캘린더, 전자결재, 문서함, 용어집입니다.

**난이도**: 시작할 때 고릅니다. 날이 갈수록 요청 간격이 하루 5분씩 짧아집니다.

| 난이도 | 업무 요청 | 그 밖에 |
| --- | --- | --- |
| 쉬움 (기본) | 70~110분마다, 출근 때 1건 | 마감 1.5배, 채점 너그러움, 예산·보고서는 2일차부터, 계산 공식과 전결 규정이 미리 보임 |
| 보통 | 45~70분마다, 출근 때 2건 | 마감 1.2배 |
| 어려움 | 30~50분마다, 출근 때 3건 | 이상한 업무 1~2건 |

**업무**

| 업무 | 하는 일 |
| --- | --- |
| 일정 조율 | 팀 캘린더에서 참석자 일정과 조건(예: 수요일 이후, 오후만)을 보고 회의를 빈 시간으로 옮기기 |
| 문서 구성 | 기획서, 주간 보고, 회의록, 장애 보고서의 섹션 순서를 끌어다 놓아 바로잡기 |
| 예산 계산 | 견적표의 금액, 소계, 부가세, 합계를 계산하고 한도를 넘으면 항목 빼기 (계산기 있음) |
| 전자결재 | 품의서·지출결의서 양식 고르기, 금액에 맞는 결재선 지정, 재무팀 참조. 30~60분 뒤 승인 또는 반려 |
| 보고서 작성 | 지표 데이터로 전환율(%p)이나 증감률(%) 계산, 두괄식 결론, 원인, 다음 계획 쓰기 |
| 메일 | 받는 사람과 참조 고르고 본문 직접 입력 |
| 문서 검토, 자료 준비, 문서 작성 | 틀린 줄 찾기, 지시에 맞는 자료 고르기, 타이핑 |

업무는 이어집니다. 예산표를 끝내면 품의를 올리라는 요청이 오고, 결재가 반려되면 고쳐서 다시 올려야 하고, 메신저 답에 따라 새 업무가 생깁니다.

**하루**

- 09:00 출근부터 18:00 퇴근 또는 22:00까지 야근
- 캘린더에 잡힌 내 회의 시간이 되면 회의에 들어가 질문에 답하기
- 커피타임·담배타임(너무 자주 가면 눈치), 점심 메뉴 선택
- 퇴근 후 팀 회식(다음 날 숙취와 지각), 동기 술자리, 혼술, 집에서 쉬기
- 하루 결산, 브라우저 자동 저장

**메신저**: 사람마다 프로필과 대화방이 있고, 말풍선으로 대화합니다. 업무 요청 카드, 빠른 답장, 기획팀 단톡방, 이상한 부탁(수락·거절)이 있습니다.

**실무 용어**: 밑줄 친 용어를 누르면 뜻과 예문이 나오고 용어집에 모입니다. 결재선, 전결, 부가세, 두괄식, 퍼센트포인트 등 30여 개.

## 3단계: 휴가와 승진

**인사·근태 메뉴**: 직급, 급여, 승진 포인트, 남은 연차, 평가 기록, 직급 체계(사원부터 사장까지)를 봅니다.

**휴가**

- 근무 중에 휴가신청서를 상신합니다. 기간(내일부터 1~3일), 휴가지(집, 국내 여행, 해외여행), 부재중 자동응답, 직무대행을 고릅니다.
- 팀장 결재가 나면 인수인계서 업무가 들어옵니다. 진행 중인 일마다 맞는 부서 담당자를 고르고 연락 기준을 정합니다.
- 휴가 날에는 오전, 오후, 저녁마다 할 일을 고릅니다. 휴가지마다 활동과 경비가 다릅니다.
- 사이사이 회사와 지인에게서 연락이 옵니다. 바로 처리하기, 짧게 답장하기, 직무대행에게 넘기기, 읽고 답 안 하기 중에 고릅니다. 해외에서는 새벽에 오기도 합니다.
- 자동응답을 켜고 인수인계서를 잘 쓸수록 연락이 줄어듭니다.
- 복귀 첫날에는 밀린 업무가 쌓여 있습니다. 기념품을 사 왔다면 평판이 오릅니다.

**인사평가와 승진**

- 금요일이 지나면 주말 휴식, 급여, 연차 1일, 주간 인사평가가 나옵니다.
- 처리율과 평판으로 S~D 등급을 받고, 등급마다 승진 포인트가 쌓입니다(S +3, A +2, B +1, C 0, D −1).
- 포인트가 차면 승진 심사를 봅니다. 실무 용어 3문제 중 2개를 맞히면 승진합니다.
- 승진하면 급여가 오르고 호칭이 바뀝니다("OO 씨" → "OO 주임님"). 출근 때 쌓인 업무와 요청 빈도도 늘어납니다.
- 지금은 과장까지 올라갈 수 있습니다. 차장부터는 4단계(업무 배당)에서 열립니다.

## 덕과 업보, 동료 관계

- **모든 선택이 장부에 남습니다.** 업무를 제대로 끝내거나, 메시지에 성의 있게 답하거나, 부탁을 들어주거나, 회식에 남으면 "덕"이 쌓입니다. 마감을 놓치거나, 하다 만 일을 두고 퇴근하거나, 메시지를 무시하거나, 회의를 빠지면 "업보"가 쌓입니다.
- **나중에 돌아옵니다.** 덕은 동료가 업무를 대신 맡아 주거나, 커피를 주거나, 윗선에 칭찬해 주는 식으로 돌아옵니다. 업보는 추가 업무, 평판 하락, 그리고 휴가 중 연락으로 돌아옵니다. 휴가 중에 온 연락에는 왜 왔는지 이유가 함께 나옵니다.
- **주간 인사평가에 다면평가**가 들어갑니다. 한 주 동안의 덕과 업보 차이로 승진 포인트가 ±1 됩니다. 승진 심사 때 면접관과의 관계도 분위기를 바꿉니다.
- **동료마다 호감도와 이야기가 있습니다.** 이서연 대리의 이직 고민, 동기 한수빈의 번아웃, 정민호 선임과의 일정 갈등, 박지훈 팀장의 사정, 최영수 부장의 시험, 고객센터와 총무팀 이야기. 내 선택에 따라 다음 이야기가 달라집니다.
- **먼저 말 걸기**: 메신저의 "동료 목록"에서 아무에게나 안부 묻기, 커피 사 주기, 업무 도와 달라고 하기, 소문 물어보기를 할 수 있습니다. 호감도가 높아야 도와줍니다.

## 변칙 업무

- 업무마다 요청 배경이 붙습니다.
- 긴급 업무: 마감이 짧은 대신 성과를 더 줍니다.
- 업무를 열어 두면 중간에 요청이 바뀔 수 있습니다 (회의 참석자 추가, 조건 변경, 예산 삭감, 수량·단가 변경, 참조 추가, 금액 정정).
- 하던 업무가 취소되기도 하고, 이미 끝낸 일이 없던 일이 되기도 합니다.
- 캘린더에서 이미 지난 시간은 흐리게 표시되고 고를 수 없습니다.

## 부서와 팀 이동

- 입사할 때 기획팀, 개발팀, 디자인팀, 영업팀 중 고릅니다. 팀마다 팀장과 사수, 단톡방, 업무 비중이 다릅니다.
- 개발팀: 버그 우선순위 분류, 롤백 계획 검토, 배포 체크리스트.
- 디자인팀: 시안 피드백 분류, 인쇄 사양 검토, 디자인 작업 순서.
- 영업팀: 견적서 작성 (할인율, 공급가액, 부가세), 리드 분류, 계약서 검토, 제안서 목차.
- 인사·근태 메뉴에서 전보를 신청할 수 있습니다. 평판이 낮으면 반려되고, 승인되면 다음 날 새 팀으로 출근합니다. 떠난 팀 사람들과는 서먹해지고 포인트가 1 줄어듭니다.

## 파일 구조

| 파일 | 내용 |
| --- | --- |
| `index.html` | 화면 뼈대 |
| `css/style.css` | 그룹웨어 스타일 (다크 모드, 모바일 대응) |
| `js/core.js` | 공통 도구, 수치, 모달, 용어, 저장 |
| `js/generators.js` | 업무 만들기 (캘린더, 예산, 보고서 숫자를 매번 새로 생성) |
| `js/apps.js` | 업무 종류별 화면과 채점 |
| `js/messenger.js` | 메신저 |
| `js/main.js` | 하루 진행과 화면 전환 |
| `js/career.js` | 직급, 주간 인사평가, 급여, 승진 심사, 휴가 신청 |
| `js/vacation.js` | 인수인계서 업무, 휴가 하루, 휴가 중 연락, 복귀 |
| `js/twists.js` | 요청 배경, 긴급·변경·취소 업무, 덕과 업보 기록 |
| `js/relations.js` | 호감도, 동료 이야기, 먼저 말 걸기, 덕·업보가 돌아오는 일 |
| `js/teamwork.js` | 부서별 업무, 분류·견적서 업무, 팀 이동 |
| `js/office.js` | 장면(컷씬), 단톡방, 휴식·점심·야근 장면, 호출, 소문과 정보 |
| `js/ai.js` | AI 대화 (자유 대화, 직접 쓴 답 채점) |
| `js/data/` | 사람, 용어, 업무, 메시지, 공지, 직급, 휴가지, 부서 데이터 |

새 업무나 용어는 `js/data/` 아래 파일만 고치면 됩니다. 게임 텍스트에서 `{{용어}}`처럼 감싸면 용어 사전과 연결되고, `{me}`는 플레이어 호칭으로 바뀝니다.

## 회사 안의 이벤트

- 단톡방: 팀 단톡방, 입사 동기방, 친한 사람들(호감도 30 이상)의 점심 메이트 방에서 하루 종일 대화가 오간다. 가끔 나에게 말을 걸고, 답에 따라 방 사람 모두의 호감도가 바뀐다.
- 커피·담배타임: 누군가를 마주치는 장면이 나온다. 친한 사람일수록 잘 마주친다. 선택에 따라 호감도, 용어, 소문, 정보가 생긴다.
- 점심: 누구와 먹는지에 따라 다른 장면이 나온다. 야근: 야식, 팀장님 면담, 친구 전화 같은 장면이 나온다.
- 호출: 놓친 업무나 업보가 있으면 팀장님에게 불려 가 혼난다. 아니면 일을 배우거나(퀴즈), 인수인계를 받는다. 꼼꼼히 받으면 마감이 넉넉해진다.
- 소문과 정보: 소문에는 쓸모 있는 정보가 붙어 있다. 예를 들어 "최 부장님은 첫 줄에 결론 없으면 반려한대"를 들으면 이틀 동안 보고서 업무에 힌트가 뜨고 통과하면 성과 +3. 정보는 왼쪽 프로필 카드에 보인다 (`js/data/office.js`의 `RUMORS`, `PERKS`).

## AI 대화

claude.ai 플레이 링크에서는 메신저에서 동료에게 아무 말이나 직접 쓸 수 있습니다. 처음 쓸 때 Claude 사용을 허락하면, 플레이어 본인의 Claude 계정으로 답이 옵니다. API 키는 필요 없습니다.

- 자유 대화: 동료 대화방이나 단톡방 아래 칸에 쓰면, 그 사람의 성격과 말투(`js/data/personas.js`), 호감도, 나와 있었던 덕·업보를 보고 답합니다. 말에 따라 호감도와 멘탈이 바뀌고, 확실히 착하거나 무례한 말은 장부에 남습니다. 말로 올릴 수 있는 호감도는 하루 한 사람당 8까지입니다.
- 답이 필요한 메시지: 선택지 대신 직접 써도 됩니다. AI가 가장 가까운 선택지를 골라 이야기와 업무는 그대로 이어지고, 상대가 내 말에 맞춰 답합니다. 업무 대화는 적절함·내용·용어·명확성으로 채점됩니다.
- 플레이 링크 밖(로컬 서버 등)에서는 `js/ai.js`의 `endpoint`에 Claude API를 부르는 서버 함수 주소를 넣어야 AI가 켜집니다. API 키는 게임 코드에 넣지 않고 서버 함수에만 둡니다. 둘 다 없으면 선택지로만 플레이합니다.
